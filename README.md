# نیازتو — نسخه 3.10.4 Preview

## حالت پیش‌نمایش ژاکت
این بسته برای لینک پیش‌نمایش محصول در ژاکت آماده شده است. به‌صورت پیش‌فرض `PREVIEW_MODE=1` است؛ بنابراین بازدیدکننده بدون ثبت‌نام و ورود می‌تواند فروشگاه، پروفایل نمایشی و پنل مدیریت را بررسی کند. یک حساب مدیر نمایشی داخلی با نام `__preview_admin__` برای این حالت ساخته می‌شود.

برای نصب واقعی مشتری، مقدار زیر را در `.env` به `0` تغییر دهید:

```env
PREVIEW_MODE=0
```

در حالت عادی، احراز هویت و سطح دسترسی واقعی برنامه فعال است.

## اجرای پروژه
```bash
pip install -r requirements.txt
python run.py
```

آدرس پیش‌فرض: `http://127.0.0.1:5000`
